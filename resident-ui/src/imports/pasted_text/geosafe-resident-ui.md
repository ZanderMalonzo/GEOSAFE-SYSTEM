# Figma AI Prompt — GeoSafe Resident Mobile App

## Project Overview

Design a **high-fidelity mobile-first Progressive Web Application (PWA)** named **GeoSafe**.

GeoSafe is a **Geolocation-Based Disaster Reporting and Emergency Assistance System** for residents of Barangay Bayanan. The application helps citizens report disasters, request rescue assistance, receive emergency alerts, locate evacuation centers, monitor family safety, and communicate with local responders during emergencies.

The interface should feel trustworthy, calm, modern, and easy to use under stressful situations.

The application should follow **Google Material Design 3** guidelines while maintaining a clean government service appearance.
